## Blog: Semiconductors Tinkering
บล็อกรวมรายงานการเรียนรู้เรื่องชิปและเซมิคอนดักเตอร์ สำหรับคนทั่วไปและนักทดลอง
A bilingual (Thai / English) single-page blog collecting notes on chips and semiconductors.

### เนื้อหา / Contents

1. **RAM และ SSD** — RAM and SSD: technology, types and the key memory players
2. **ออกแบบชิประดับสูงอย่างไร** — How advanced chips are designed: tools, teams and yearly gains
3. **ชิปตามฟังก์ชัน การสร้าง และอุปสงค์-อุปทาน** — Chips by function, how they are built, and supply vs demand

### วิธีเปิด / How to view

เปิดไฟล์ `index.html` ในเบราว์เซอร์ได้เลย กดปุ่ม **ไทย / EN** ที่เมนูด้านซ้ายเพื่อสลับภาษา
Open `index.html` in any browser. Use the **ไทย / EN** toggle in the sidebar to switch language.

Everything is in one self-contained file (fonts load from Google Fonts when online).
If GitHub Pages is enabled for this repository, the page is served from the `main` branch root.
